# 🎮 Game Zone Counter

Це консольна програма на C++, яка допомагає автоматизувати розрахунок щоденного прибутку комп'ютерного клубу. 

### Що реалізовано:
* Введення кількості відвідувачів, вартості квитків та витрат.
* Розрахунок загального (брудного) прибутку.
* Розрахунок чистого прибутку з урахуванням витрат на електроенергію.
* Проєкт створено виключно на базі матеріалів **Chapter 1 (C++ Basics)** ресурсу LearnCpp.
